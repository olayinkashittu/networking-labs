# 🌐 Cisco Networking Lab

## 📌 Project Overview

This project documents my hands-on Cisco networking practice using Cisco Packet Tracer.

The lab focuses on basic network configuration, switching, IP addressing, and switch security.

## 🎯 Objectives

- Configure a basic network topology
- Configure IP addresses
- Configure network devices
- Test connectivity between devices
- Configure switch security
- Practice basic Cisco IOS commands
- Troubleshoot network connectivity

## 🛠️ Tools Used

- Cisco Packet Tracer
- Cisco IOS
- PC and switch devices
- Ethernet connections

## 🔧 Networking Topics

- IP Addressing
- MAC Addresses
- Switching
- Basic Cisco IOS Configuration
- Switch Port Security
- Network Connectivity Testing
- Troubleshooting

## 🔐 Switch Port Security
